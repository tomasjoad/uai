# uai — agente local con perfil propio

Agente personal que corre en tu máquina: conversa contigo, mantiene un perfil
tuyo (gustos, decisiones, preferencias) que se actualiza con cada conversación, usa
herramientas MCP con tu aprobación y comparte con el exterior solo lo mínimo.

- Diseño, decisiones y roadmap por fases: [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md)
- Núcleo (F1, Python + uv): [agent-core/](agent-core/README.md)
